# Sawti · صوتي

Text-to-speech in 600+ languages (including Standard Arabic and major
dialects) with voice design and consent-gated voice cloning, built on
[OmniVoice](https://github.com/k2-fsa/OmniVoice).

Source: https://github.com/alfadni/Sawti_zato — this Space is deployed from
`deploy/huggingface/` by the "Deploy to Hugging Face Space" GitHub workflow.

Generated audio is synthetic. Do not use it to impersonate anyone or to pass
voice-based identity checks.
